# Mon QG — l'app perso

Une vraie application sur le téléphone, avec son icône, pour voir l'Usine et répondre aux décisions sans passer par claude.ai.
Elle vit ici, dans sa propre boîte, séparée de l'Usine (`usine-a-projets`) et de la Bibliothèque.

- [`app/`](app/README.md) : l'app installable (PWA) et son relais de notifications.
- [`docs/etude-inspiration.md`](docs/etude-inspiration.md) : l'étude de bonnes apps de pilotage (pages publiques et open source MIT, aucun code copié).

**État : développement seulement.** Rien n'est en ligne, rien n'est payé. La mise en ligne attend votre « oui ».
